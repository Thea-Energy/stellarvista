# StellarVista
A Python package for DAGMC model inspection, mesh inspection, tally visualization, particle track visualization, and more for OpenMC with Pyvista.

## Visualization Features
<p align="center">

</p>
- DAGMC geometry and mesh
- Tallies
    - Unstructured mesh
    - Regular mesh
    - Material filter
- Particle tracks
- Weight windows
