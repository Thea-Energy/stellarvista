# Stellarvista
A Python package for DAGMC model inspection, tally visualization, and more for OpenMC with Pyvista.

<p align="center">
<img src="https://github.com/Thea-Energy/stellarvista/raw/main/doc/logo.png" width="100%">
</p>

## Visualization Support
* DAGMC geometry and mesh
* Tallies
    * Unstructured mesh
    * Regular mesh
    * Material filter
* Particle tracks
* Lost Particles
* Weight windows
* Point Sources
